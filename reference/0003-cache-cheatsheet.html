Glossary

Line / blockThe unit moved into a cache
SlotA place that holds a line and its metadata
SetThe group of slots a line may occupy; chosen by the index
WaySlots per set, or associativity
Data sourceThe next level down, such as memory
DirtyUpdated in the cache but not yet in the source
StrideDistance between consecutive accesses
Local / remoteThis core's operation / another core's operation

Address bits

| tag | index | offset |. b = log₂(line size). slots = size ÷ line size. sets = slots ÷ ways. s = log₂(sets). t = m − s − b. size = sets × ways × line size. 1 KB = 1024 bytes.

Times

Average = h × hit + (1 − h) × total miss. Memory speedup = old ÷ new average. Required hit rate: set the average to old ÷ speedup and solve for h.

Amdahl: speedup = 1 / ((1 − a) + a/k). Tnew = Told × ((1 − a) + a/k). Limit: 1 / (1 − a).

Multi-level miss: add every transfer that must happen, plus one for each dirty eviction on that link, then the final L1 access.

Replacement: evict the line…

Belady: used farthest in the future. LRU: used farthest in the past. LFU: smallest count (the count restarts after eviction, per slides 3.3). MRU: used most recently. Hardware: often random.

Write latency (c = cache, d = source)

Write-back: faster, coalesces writes. Write-through: no window of vulnerability, simpler. Allocate: good for many writes per line. No-allocate: avoids cache clutter from write-only data.

Stride

s ≥ L: every access misses. s < L: hit rate = 1 − s/L on a first aligned pass. C is row-major: column stride = element × columns.

Trace: skips lines → more than a line. Each line once → exactly one. Mix of 1 and 2 → between half and one. Exactly 2 → half. Some 3+ → under half.

Array too big: line number mod sets gives the set. In a set with more lines than ways under LRU, all of its lines miss on every pass. Others miss once. Direct-mapped can beat fully associative LRU on these cycles.

Same address: M or E can pair only with I; S pairs with S or I. Same slot: any pair is possible, because the tags can differ. Communication: read hit no; read miss yes; write hit maybe; write miss yes; clean eviction no; dirty eviction yes.

Parallelism

Pipeline, superscalar, out-of-order, hyperthreading (register copies, shared logic), multicore (MIMD), vector/GPU (SIMD), accelerators, distributed (no shared memory), multitasking (OS illusion).

Stalls

ALU then use: 3 / 0 / 0. Load then use: 3 / 1 / 1. jXX: 2 / 2 / 0. ret: 3 / 3 / 3. Columns: stalling only / + forwarding / + prediction in the best case.
