File descriptors

fd tableper process; 0 stdin, 1 stdout, 2 stderr; open returns the lowest free fd
open file tableone entry per open(): offset, mode, refcount
v-node tableone entry per file: in-memory inode
fork / dup / dup2share the open-file entry → shared offset
two separate openstwo entries → separate offsets, same data
cmd < ffd = open(f, O_RDONLY); dup2(fd, 0);
cmd > ffd = open(f, O_WRONLY|O_CREAT|O_TRUNC, 0644); dup2(fd, 1);

Course conventions (PrairieLearn)

nothing read yetIOs = 1 inode + index levels + 1 data. Single extent = 2
multi-level depthonly as deep as the file needs: ≤ p blocks → 1 level, ≤ p² → 2
max KBextent: max × B/1024 · flat: idx blocks × p × B/1024 · multi: r·pL × B/1024 · hybrid: (d + s·p + p² + p³) × B/1024
multi positionsLevel 1 = root; level k = ⌊LBN / pL−k⌋ mod p; unused = −1
hybrid positionsmetadata: directs, then indirects, double, triple. Double: r = LBN − d − p; dbl = ⌊r/p⌋, ind = r mod p
direntu32 ino · u16 reclen · u8 type (4 DIR, 8 REG, 10 LNK) · u8 namlen · name. Little-endian; hop by reclen; ino 0 = deleted; reclen = 8 + namlen + 1 rounded up to 4
shared offset?dup/dup2/fork/threads: yes · second open(): no
v6 vs ext2v6: superblock block 1, free list, 8 addrs (8 direct | 7 ind + 1 dbl), 16-byte dirent (2 + 14). ext2: groups, bitmaps, 12+1+1+1, variable dirent
