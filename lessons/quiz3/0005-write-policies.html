Write Policies

Two independent decisions: when does the data reach the source, and does a write miss load the line?

Your win for today: give the write latency for all four combinations, and find a break-even hit rate (R3.10). About 15 minutes.

Warm-up: recall

L1 hit 2, L1↔L2 transfer 10, L2 hit. A read misses L1 and evicts a dirty line. Time?

10 (write back) + 10 (fetch) + 2 = 22. Lesson 4.

1 · The decisions

What it doesAdvantages
Write-throughwrites cache and sourceNo window where only the cache has the new data; simpler
Write-backwrites cache, sets dirty bit, writes source on evictionFaster; repeated writes coalesce into one
Write-allocatea write miss loads the line firstFaster for many writes in one line; matches read behaviour
No-write-allocatea write miss goes straight to the sourceAvoids filling the cache with write-only or random data

The usual pairs are write-back with write-allocate, and write-through with no-write-allocate. Slides 3.4

2 · Latencies

With cache time c and source time d. Parallel writes don't add, so write-through's cache write is hidden by the slower source write. Slides 3.5, where c = 2, d = 20

Why does a write-through, write-allocate miss take 2d?

  1. It writes the source twice
  2. It reads the line twice over
  3. It writes then reads the source
  4. It evicts a dirty cache line

One source write for the new data, plus one source read to fetch the rest of the line. A write-through cache has no dirty lines.

Write-back, write-allocate, c = 2, d = 20. 80% write hits. Half of the misses evict a dirty line. Average write time in ns?

Average miss = 0.5×22 + 0.5×42 = 32. Average = 0.8×2 + 0.2×32 = 1.6 + 6.4 = 8.

Write-back, write-allocate: hit 4, clean miss 20. Write-through, no-allocate: every write 8. Assume all evictions are clean. At what hit rate are the averages equal? (2 decimals)

4h + 20(1 − h) = 8, so 16h = 12 and h = 0.75. Write-through takes 8 on hits and misses alike, which is what makes this quick.

A program writes the same word 1000 times, then its line is evicted. How many source writes for write-back and for write-through?

  1. 1 and 1 source write
  2. 1000 and 1 source writes
  3. 1 and 1000 source writes
  4. 1000 and 1000 source writes

This is write coalescing, and it counts in write-back's favour.

What must a write-back cache store that a write-through cache doesn't need?

  1. A valid bit for each line
  2. A tag for each cache line
  3. A dirty bit for each line
  4. An offset for each line

The dirty bit says the line must be written out on eviction. See the metadata list in slides 3.5.
