MSI & MESI

Every cache keeps a state per line so the cores agree on its value while talking as little as possible.

Your win for today: read a state transition off the diagram, track two cores, and name exactly where MSI and MESI differ. About 20 minutes.

Warm-up: recall

In a single-core write-back cache, which action does not communicate with the data source?

  1. A write hit on a line
  2. A read miss on a line
  3. A write miss on a line
  4. Evicting a dirty line

It only sets the dirty bit. Lesson 5.

1 · The states

A state replaces the valid and dirty bits, per line, per cache. Each core has its own state for the same line. Local means this core did it; remote means another core did.

Why E exists Read, then write, is common for private data. MSI goes I → S → M, so the write hit must send an invalidate that nobody needs. MESI goes I → E → M, and that write is silent.
Course-specific: remote read on M The course's MSI diagram has Remote R/W taking M to I, whereas its MESI diagram takes M to S on a remote read. Many other sources draw MSI with M → S. Use the course's version. The two protocols therefore differ in exactly two ways for a given start state:
1. A local read miss when no other cache has the line: MSI gives S, MESI gives E.
2. A remote read while in M: MSI gives I, MESI gives S.

A core holds a line in S and gets a write hit. Does it communicate?

  1. No; hits never communicate
  2. Yes; S must send invalidate
  3. No; S lines are always clean
  4. Yes; S must write the source

S means others may hold copies, so it must invalidate them. M and E hits are silent, which is why slides 3.7 say “maybe” for write hits in general.

Under MSI vs MESI from the same start state, which action can leave Core 1 in a different state?

  1. Core 1 read hit
  2. Core 1 write hit
  3. Core 2 reads line
  4. Core 2 writes line

If Core 1 is in M, MSI gives I and MESI gives S. Read hits never change state, a write hit always ends in M, and a remote write always ends in I.

3 · Which pairs can exist? (R3.14)

Read the question carefully Same address: at most one cache can be in M or E. The possible pairs are I with anything, or S with S.
Same slot (same index only): the two caches may hold different tags, meaning different lines, so any pair is possible.

Two MESI caches, same address. Which pair is possible?

  1. M and S
  2. E and E
  3. M and M
  4. S and S

M and E are exclusive by definition, so they can pair only with I.

Two MESI caches, same slot, same index but no statement about tags. Which pair is impossible?

  1. M and M
  2. E and S
  3. M and E
  4. None of them

Different tags are different lines, so the states are unrelated.
