Replacement Policies

When a set is full, something has to go. The policy decides what.

Your win for today: trace any sequence under any policy, and say which workload each policy suits. About 15 minutes.

Warm-up: recall

Why does a direct-mapped cache not need a replacement policy?

  1. Each line has only 1 slot
  2. It never has any misses
  3. Its lines are never dirty
  4. All its sets are always full

A line can go in one slot only, so the choice is already made. Lesson 2.

1 · The policies

PolicyEvict the line…Know this
Beladyused farthest in the futureIdeal but needs the future, so it's the benchmark.
LRUused farthest in the pastFrequently good. A cycle just bigger than the cache gives 0 hits.
LFUwith the smallest use countSometimes better than LRU. Needs a count per line.
MRUused most recentlySuits cyclic scans bigger than the cache. Poor for typical temporal locality.
Randomat randomOften used in hardware, where fancy policies cost too much.

There is no perfect policy: for anything but Belady, you can build an adversarial workload. Slides 3.3

2 · Worked example (2 slots, fully associative)

A A C A C B B B A A B C

LRU. A and C load with 3 hits along the way. At the first B, C was used more recently than A, so A goes. At the next A, B was used more recently, so C goes. At the final C, B was used more recently, so A goes. Result: 7/12.

LFU. At the first B, the counts are A=3, C=2, so C goes. At the final C, the counts are A=5, B=4, so B goes, and C comes back with a count of 1. Result: 8/12. The slide shows counts restarting after eviction, and the drills do the same.

Belady. At the first B, A is next used sooner than C, so C goes. At the final C nothing else is used again, so any eviction works. Result: 8/12.

Fully associative, 2 slots, LRU. Which sequence gives a hit rate of 0?

  1. A,B,C,A,B,C,A,B,C
  2. A,B,A,B,C,A,B,A,B
  3. A,A,B,B,C,C,A,A,B
  4. A,B,A,C,A,B,A,C,A

Each access evicts exactly the line needed next. That is the adversarial workload from slides 3.3.

Same cache, sequence A,B,C,A,B,C. Which policy gets more hits?

  1. LRU gets 2 hits, MRU none
  2. MRU gets 2 hits, LRU none
  3. Both policies get 2 hits
  4. Both policies get 0 hits

LRU always throws out what is coming next. MRU keeps A: at C it evicts B, then A hits, B misses and evicts A, then C hits.

Drill. Random policies. Get five in a row.

Primary source Slides 3.3. MRU is on the learning goals, but the slides don't cover it; check P14 for its exact wording.
Now test it Trace the slide sequence A,A,C,A,C,B,B,B,A,A,B,C on paper under Belady, LRU and LFU. You should get 8/12, 7/12 and 8/12.
