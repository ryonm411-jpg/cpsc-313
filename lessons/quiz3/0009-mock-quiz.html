Each answer is marked immediately, so write your reasoning first. Go back to the lesson for anything you miss. This is my own practice set, not a copy of the real quiz.

1 · Hierarchy

Which order runs from fastest to slowest?

  1. Registers, L1, L3, DRAM, SSD
  2. L1, registers, L3, DRAM, SSD
  3. Registers, L3, L1, DRAM, SSD
  4. Registers, L1, L3, SSD, DRAM

Slides 3.1.

2 · Locality

A loop sums one small array over and over. Which locality does it show?

  1. Temporal locality only
  2. Spatial locality only
  3. Both kinds of locality
  4. Neither kind of locality

Nearby elements (spatial), and the same elements again on each pass (temporal).

3 · Bits

A 4-way, 64 KB cache has 64-byte lines. How many index bits?

65536 ÷ 64 = 1024 slots. ÷ 4 = 256 sets. log₂(256) = 8.

4 · Bits

Same cache, 48-bit addresses. How many tag bits?

48 − 8 − 6 = 34.

5 · Sets

A cache has 256 sets and 256-byte lines. Which address could be in set 0x4A?

  1. 0x12344A7F
  2. 0x1234A47F
  3. 0x4A123400
  4. 0x12344B7F

The offset is the last two hex digits, and the index is the two digits before that. 0x12344A7F has index 4A.

6 · Parameters

Keep the size, ways and address width fixed, and halve the line size. What happens?

  1. index +1, offset −1, tag same
  2. index −1, offset −1, tag +2
  3. index same, offset −1, tag +1
  4. index +1, offset +1, tag −2

Half the line size gives twice the slots, so twice the sets. One bit moves from offset to index.

7 · Average

Memory alone takes 120 ns. A cache hit takes 4 ns, and a total miss takes 120 ns. What hit rate gives a memory-system speedup of 6? (2 decimals)

Target average = 20. 4h + 120(1 − h) = 20, so 116h = 100 and h ≈ 0.86.

8 · Multi-level

L1 hit 5; L1↔L2 transfer 30; L2↔memory transfer 60; write-back. A read misses L1 (clean eviction) and misses L2 (dirty eviction). Time in ns?

60 + 60 + 30 + 5 = 155.

9 · Multi-level

Same caches. 50% hit L1. Of those that miss, 80% hit L2. All evictions clean. Average in ns? (2 decimals)

L2 hit = 35; L2 miss = 95. 0.5×5 + 0.5×(0.8×35 + 0.2×95) = 2.5 + 0.5×47 = 26.

10 · Amdahl

A program takes 200 s and spends 50% of its time in a part made 5× faster. New time in s?

200 × (0.5 + 0.5/5) = 200 × 0.6 = 120.

11 · Replacement

Fully associative, 2 slots, LRU, sequence A,B,A,C,B,C,A. How many hits?

A miss, B miss, A hit. C misses and evicts B. B misses and evicts A. C hits. A misses. Hits at accesses 3 and 6.

12 · Replacement

Which policy needs knowledge of future accesses?

  1. Least recently used
  2. Least frequently used
  3. Belady's algorithm
  4. Random replacement

It evicts the line used farthest in the future, so it serves as a benchmark rather than a buildable policy.

13 · Writes

Write-through, write-allocate. Cache 3 ns, source 25 ns. Latency of a write miss in ns?

One source write plus one source read: 25 + 25. The cache time is hidden. Slides 3.5, Example 2.

14 · Writes

Write-back, write-allocate. Cache 3 ns, source 25 ns. Write miss evicting a dirty line, in ns?

25 + 25 + 3.

15 · Writes

Write-back, write-allocate: hit 5, clean miss 25. Write-through, no-allocate: every write 10. All evictions clean. Break-even hit rate? (2 decimals)

5h + 25(1 − h) = 10, so 20h = 15 and h = 0.75.

16 · Writes

Random writes across a huge array, never read back. Which miss policy suits it best?

  1. Write-allocate always
  2. No-write-allocate
  3. Allocate on evict only
  4. Allocate every other

It avoids filling the cache with write-only data. Slides 3.4.

17 · Stride

double a[100][100], 64-byte lines, one pass, row by row, cold cache big enough to hold it. Hit rate? Assume line-aligned. (3 decimals)

Stride 8 in 64-byte lines: 8 accesses per line, 1 miss. 7/8.

18 · Stride

Same array, column by column. What is the stride, and do you get spatial hits?

  1. 8 bytes, and spatial hits
  2. 800 bytes, no spatial hits
  3. 100 bytes, no spatial hits
  4. 64 bytes, and spatial hits

C is row-major, so neighbours in a column are one whole row apart: 100 × 8.

19 · Stride

Trace A,A,A,B,B,B,C,C,D,D,D. Letters are consecutive lines. What is the stride?

  1. More than one line size
  2. Exactly one line size
  3. Exactly half a line size
  4. Under half a line size

At half a line, each line gets exactly 2 accesses. Some lines get 3 here, so the stride is smaller than that.

20 · Stride

Cache: 64 sets, 4-way, 16-byte lines. An array 10 lines larger than the cache, line-aligned, is read with stride 16, 100 times, LRU. Total misses?

256 + 10 = 266 lines. Sets 0–9 hold 5 lines: 50 lines miss on all 100 passes = 5000. The other 54 sets hold 216 lines, each missing once. Total 5216.

21 · Coherence

MESI. A line is in E in this cache, and another core reads it. New state?

  1. M, and it writes back
  2. S, with no write-back
  3. I, with no write-back
  4. E, with no change at all

E is clean, so no write-back; a second copy now exists, so S.

22 · Coherence

In MSI on the course diagram, a line is in M, and another core reads it. New state?

  1. S, after a write-back
  2. I, after a write-back
  3. M, with no message sent
  4. S, with no write-back

Remote R/W takes M to I in the course MSI. MESI would give S.

23 · Coherence

What is the advantage of MESI over MSI?

  1. Read hits become cheaper
  2. A silent write after a sole read
  3. Evictions become free
  4. Fewer states to store

E → M needs no invalidate.

24 · Coherence

Two MESI caches, same address. Which pair can occur?

  1. E and S
  2. E and I
  3. M and S
  4. M and E

M and E can pair only with I.

25 · Parallelism

A GPU applying one operation to many pixels is best described as…

  1. SISD
  2. SIMD
  3. MISD
  4. MIMD

One instruction, many data values.

26 · Hazards

Stalling and forwarding, no prediction: mrmovq 0(%rax), %rbx followed by addq %rbx, %rcx. Stalls?

Load/use costs 1 even with forwarding.

27 · Hazards

Stalling only, with no forwarding or prediction: a ret. Stalls?

The return address is known only after Memory.
