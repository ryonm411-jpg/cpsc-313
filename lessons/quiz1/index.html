Quiz 1 Retake — Tonight's Plan

Three focused lessons built around the two things you said bit you: reading/writing C↔Y86 (and spotting when the code was changed), and the stack-frame "where do I write, and at what address?" question.

This is Quiz 1, not Quiz 2 These pages are deliberately kept in lessons/quiz1/, away from the pipelining material. Nothing here is about forwarding, hazards, or CPI.

What the quiz tests

From the official learning goals, Quiz 1 is the ISA + implementation unit:

  • What an ISA is; describe what an instruction does in plain English; write the shorthand form (R[rB] = R[rA] * R[rB]).
  • Map between C and the compiler's assembly; convert C → Y86; describe Y86 in plain English.
  • Calling conventions: define, give an example, write conforming code; set up and tear down a call frame.
  • Assembler directives; assembly ⇄ machine-code byte encoding.
  • The SEQ instruction phases, in order, and the notation for each (valE ← valB + (-8)); reason about a new instruction.

Study order (about 75 min)

  1. Lesson 1 — C ⇄ Y86 and "did it change?" (30 min). Your #1 struggle. Loop shapes, if/else, and a checklist for catching altered assembly.
  2. Lesson 2 — Stack frames, arrays & the address question (30 min). Your #2 struggle. Frame layout, array addressing, and the hex "where does the write land" problem with %rbx.
  3. Lesson 3 — Grab bag (15 min). Calling conventions cheat, directives, shorthand notation, and encoding/SEQ quick review.
