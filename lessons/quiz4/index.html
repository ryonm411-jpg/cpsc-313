Quiz 4: The Plan

Built for a complete beginner from the QI4.1 learning goals and the R4 practice questions. Every lesson has a random drill you can repeat.

Lessons

  1. Disks from scratch. Platters, tracks, sectors; why disks aren't memory; seek + rotation + transfer; "what changes if…". R4.6, R4.7.
  2. File descriptors and the three tables. open/read/write/close, fork, dup, shared offsets, I/O redirection. R4.4, R4.5.
  3. Index structures. LBN vs PBN, flat, extents, hybrid inode, max file size, block-size trade-offs. R4.8–R4.12.
  4. Directories, paths and links, plus the MSI/MESI comparison. R4.2, R4.3, R4.13–R4.15.
  5. Mock Quiz 4. 25 questions across all five topics, 50 minutes, with a score-yourself table.
  6. Weakness finder. About 70 questions and 9 random drills across all nine Quiz 4 topics (including v6/ext2 and directory hex dumps), with a live score per topic and a results button to paste back to me.
  7. IOs and max sizes, the course's way. The inode read counts; trees only as deep as needed; sizes in KB. I24.1–3, I26.3, L8-Ind.9–12.
  8. Walking an index. Position at each level, hybrid positions, following pointers through a block table. L8-Ind.13–14, I24.4–5, Tutorial 9.
  9. Directory hexdumps. The macOS dirent: little-endian, hop by reclen, inode 0 = deleted. I25.1–4.
  10. Shared offsets, v6 vs ext2. dup2, threads and separate opens; superblock, free list, bitmaps, dirent size. I22, P24, I26.
